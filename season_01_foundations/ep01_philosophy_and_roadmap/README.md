### 📖 What This Episode Is About

In this premiere episode, we set the foundational vision for **TorchPy**:

1. **Why Modern AI Tutorials Fail:** We examine why calling high-level library wrappers teaches zero fundamental intuition, and why 400-page academic math textbooks fail to connect theory with runnable code.
2. **What is a Neuron? (Arithmetic, Not Biology):** We demystify the artificial neuron into its four simple moving parts:
   * **Inputs ($x$):** The raw features fed into the system.
   * **Weights ($w$):** The learnable importance assigned to each input.
   * **Bias ($b$):** The baseline threshold determining how easily a neuron fires.
   * **Activation Function ($\sigma$):** The squashing mechanism (like Sigmoid) turning raw sums into probabilities.
3. **The 4-Season Master Roadmap:** We outline the entire journey ahead—moving step-by-step from one solitary neuron in pure Python to an aligned 42-million parameter conversational Large Language Model.
